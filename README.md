# Bernard Obeng Anim — Virtual Business Card

Static single-page business card. No build step: open `index.html` or serve the folder.

- Colors/typography follow the PhiNova brand (navy, steel, canvas, ink; Geist)
- "Save contact" generates a `.vcf` in the browser; edit the `contact` object in `script.js`
- Soft palette; light or dark follows the visitor's device setting, with a toggle
- `qr.svg` is a custom-styled QR (rounded modules, PhiNova colors, "BA" monogram, error-correction level H) pointing to https://grandmasylar.github.io/Grandma/; regenerate it if the URL changes
