# Bernard Obeng Anim — Virtual Business Card

Static single-page business card. No build step: open `index.html` or serve the folder.

- Colors/typography follow the PhiNova brand (navy, steel, canvas, ink; Geist + Geist Mono)
- "Save contact" generates a `.vcf` in the browser; edit the `contact` object in `script.js`
- Night theme by default, day theme via the toggle
